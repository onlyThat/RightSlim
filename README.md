# RightSlim · 右键菜单瘦身大师

一个傻瓜式的 Windows 右键菜单管理器。**打勾 = 显示，取消勾选 = 隐藏**，不用碰注册表。
改之前能先**预览对比**，确认无误再保存生效，随时可一键还原。

> 装了一堆软件后，右键点个文件，菜单长到屏幕装不下、还卡一下？这个工具把右键菜单项列成一张表，勾一下就开关，小白也能用。

## 下载安装

前往 [**Releases**](https://github.com/onlyThat/RightSlim/releases) 页面下载最新安装包：

| 文件 | 说明 |
| --- | --- |
| `RightSlim-Setup-<版本>.exe` | 安装包（推荐）。双击安装，自动创建开始菜单/桌面快捷方式，安装时会请求管理员权限 |

安装后从开始菜单打开「右键菜单瘦身大师」即可。卸载走「设置 → 应用」或开始菜单里的卸载快捷方式。

**系统要求**：Windows 7 及以上（Win10/11 最佳）。基于 .NET Framework 4.x（系统自带，无需另装）。

> 为什么需要管理员权限？因为启停右键菜单项要写 `HKEY_LOCAL_MACHINE` 注册表。程序不会联网、不会上传任何数据。

## 它能解决什么

装了几个软件之后，右键点个文件，菜单能长到屏幕装不下——7-Zip、百度网盘、各种 AI 工具、压缩、共享……一屏放不下，调出菜单还要卡一下。

传统办法是改注册表，小白劝退。这个工具把所有右键菜单项列成一张表，勾一下就能开关，而且改之前能先**预览**，确认无误才真正生效。

## 核心特性

- **一目了然**：列出所有右键菜单项，每项配一句「作用说明」，告诉你它到底是干什么的
- **先预览、后生效**：勾选/取消**只记录意图**，点「保存并应用」才真正写注册表
- **左右对比预览**：左边「现在的右键菜单」，右边「保存后的样子」，被隐藏的标红加删除线，新增的标绿
- **无损可逆**：所有隐藏都能勾回来恢复；COM 扩展的原始值备份在 `HKEY_CURRENT_USER\Software\RightSlim\Backup`
- **核心项保护**：想隐藏"复制""删除""属性"这类系统常用操作时，保存前会二次弹窗警告
- **零依赖**：单文件 exe，无需 .NET 安装包之外的任何运行库

## 用法

1. 打开程序（会弹 UAC 授权，点「是」）
2. 列表里就是当前系统所有的右键菜单项，每项都有「作用说明」
3. **勾选 / 取消勾选只记录你的意图，不会立刻改注册表**——被改动的行会变绿（将显示）或变橙（将隐藏）
4. 点 **「预览效果」**：左右对比「现在的右键菜单」和「保存后的样子」，被隐藏的项标红加删除线，新增的标绿
5. 确认没问题，点 **「保存并应用」**（预览窗口里也能直接点），才会真正写入注册表并立即生效

> 设计原则：**不确认就不落地**。随便勾着玩不会影响你的系统。

### 界面说明

| 元素 | 作用 |
| --- | --- |
| 位置下拉框 | 只看某类位置（文件 / 文件夹 / 桌面背景 / 驱动器…） |
| 搜索框 | 按名称或来源（dll 路径）过滤，找特定软件很方便 |
| 名称列 | 菜单项显示的名字。系统本地化的名字（如"复制文件地址"）会自动解析成人话 |
| **作用说明列** | 一句话告诉你这项是干什么的，以及它可能影响什么 |
| 类型列 | **操作** = 命令型菜单项；**扩展** = COM 外壳扩展（大多数第三方软件是这种） |
| 来源列 | 菜单项来自哪个 dll 或哪条命令，方便认清是哪个软件装的 |
| 底部说明栏 | 点中任意一项，完整说明 + 是否系统核心操作会显示在状态栏上方 |
| 刷新 | 装了新软件后点一下，重新读取 |
| 全部显示/全部隐藏 | 批量标记当前筛选出来的项（同样需要保存才生效） |
| **预览效果** | 打开左右对比窗口，看清保存前后的差异 |
| **保存并应用** | 把当前所有勾选改动真正写入注册表 |

### 系统核心项保护

"打开""剪切""复制""删除""重命名""属性"这类 Windows 日常操作会被标记为核心项。如果你要隐藏它们，保存前会**二次弹窗警告**，列出你正在关闭的常用功能，避免手滑把右键菜单搞残。

## 是否安全 / 能撤回吗

**能，而且是无损的。**

- 勾选/取消勾选本身**不动注册表**，只有点「保存并应用」才落盘，且会二次确认。
- 所有"隐藏"都是可逆的，勾回来再保存就恢复原样。
- 工具不会删除你的菜单项，只是把它们临时关掉：
  - 命令型菜单项：写入标准注册表值 `LegacyDisable`（微软官方支持的禁用方式）
  - COM 扩展：把注册表默认值临时置空，原始值备份在
    `HKEY_CURRENT_USER\Software\RightSlim\Backup`，还原时写回。
- 所以即使工具坏了，你的备份还在，不会丢东西。

## 从源码构建

本项目**零第三方依赖**，用 Windows 自带的 .NET Framework 编译器就够：

```bat
build.bat
```

产物在 `build\RightSlim.exe`（单文件，约 38 KB，无运行时依赖）。

需要：Windows 7 及以上，自带 .NET Framework 4.x（Win10/11 都自带）。

### 生成安装包

安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 后：

```bat
build.bat
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer\RightSlim.iss
```

产物在 `dist\RightSlim-Setup-1.0.0.exe`，即 Release 中提供的安装包。

## 实现要点

- **多位置扫描**：`*`（文件）、`AllFilesystemObjects`、`Directory`、`Folder`、
  `Directory\Background`（桌面空白处）、`Drive`，同时读 HKCU 和 HKLM。
- **HKCU 优先**：同一个菜单项在两处都存在时，以 HKCU 为准（用户级覆盖系统级）。
- **禁用 Handler 的正确姿势**：Windows 规则是「ContextMenuHandlers 子键若没有默认值，
  就把**键名本身**当 CLSID」，所以这里不能删默认值（删了反而是启用），必须写空串。
  裸 GUID 命名的系统扩展项就是靠这个规则生效的，工具已正确处理。
- **意图与实况分离**：每个菜单项同时有 `Enabled`（注册表实况）和 `DesiredEnabled`（用户勾选意图）。
  界面只改意图，`保存并应用` 时才把两者的差异批量写入注册表——这就是"先预览、确认才生效"的实现基础。
- **核心项识别用精确匹配**：`IsCore` 先去加速键括号再精确比较，绝不用前缀/子串匹配，
  否则 "Copy as Path Menu""Open Folder as…" 这类第三方项会被 "copy""open" 误伤成系统核心操作。
